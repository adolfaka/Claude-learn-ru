## intro
- minutes: "около 20 минут"
- why: "Сделайте два изменения из бэклога одновременно, чтобы сессии не трогали файлы друг друга."
- can: "запускать две сессии Claude Code одновременно, каждую в своём git worktree (рабочей копии git в отдельной папке), и сливать их работу в одну ветку"
- payoff: "запускать две сессии Claude Code одновременно, каждую в своём git worktree (рабочей копии git в отдельной папке), и сливать их работу в одну ветку"
- read: "[Isolate subagents with worktrees](https://code.claude.com/docs/ru/worktrees#isolate-subagents-with-worktrees): `isolation: worktree` во frontmatter субагента даёт каждому запуску собственный checkout."
- need-repo: "Один из ваших репозиториев с командой запуска тестов и без незакоммиченных изменений: он должен быть на ветке по умолчанию и актуален относительно удалённого репозитория, куда вы можете сделать push"

## ladder

### закоммиченный `.gitignore` игнорирует `.claude/worktrees/`, но не остальное в `.claude/`
- narrow "Ни один закоммиченный `.gitignore` не игнорирует": Есть ли вообще в закоммиченном .gitignore строка для папки worktrees?
- narrow "но это правило не закоммичено": Правило записано в .gitignore, но ещё не закоммичено?
- narrow "игнорирует только `.git/info/exclude`": Правило есть только в файле, который git никогда не коммитит?
- narrow "не даёт игнорировать `.claude/worktrees/`": Отменяет ли правило строка, которая начинается с !?
- narrow "скрыла бы настройки, которые вы коммитите для команды": Правило захватывает в .claude/ больше, чем папку worktrees?
- hint: "Закоммиченный `.gitignore` игнорирует `.claude/worktrees/` и не игнорирует остальное содержимое `.claude/`."
- bottom: "git check-ignore -v .claude/worktrees/x"

### `.practice/a-1-worktrees.txt` перечисляет два worktrees в `.claude/worktrees/`, чьи коммиты разошлись друг с другом, и оба изменения есть в вашей ветке
- narrow "Пока обе сессии worktree существуют": Вы уже сохранили список?
- narrow "— не список из": Файл получен из списка --porcelain или из другой команды?
- narrow "Запускайте каждую сессию командой": Показывает ли список оба worktrees в .claude/worktrees/?
- narrow "Сохраните список из основного checkout этого репозитория": Список сохранён в этом репозитории?
- narrow "сохранён до того, как обе сессии закоммитили": Список сохранён до того, как обе сессии закоммитили?
- narrow "в вашей текущей ветке": Изменение каждой сессии уже есть в вашей ветке?
- hint: "сохраните файл после того, как обе сессии закоммитят, и до удаления любого worktree."
- bottom: "git worktree list --porcelain > .practice/a-1-worktrees.txt"
- back: Y4 Сохраните список, пока существуют оба worktrees и в каждом уже есть коммит.

### ни одного из этих worktrees больше нет
- narrow "не найден": Список из части 4 всё ещё на месте?
- narrow "не перечисляет ни одного worktree в": Называет ли список worktrees, которые нужно удалить?
- narrow "сессия Claude Code в нём ещё работает": В этом worktree всё ещё открыта сессия Claude Code?
- narrow "всё ещё существует и заблокирован": Вы вышли из всех сессий Claude Code, открытых в этом worktree, прежде чем удалять его?
- narrow "хотя его папки уже нет": Папка worktree исчезла, а git его так и не удалил?
- narrow "всё ещё существует: когда его ветка будет слита": Worktree всё ещё на месте после слияния его ветки?
- hint: "Если не проходит третий пункт, выйдите из всех сессий Claude Code, ещё открытых в worktree, который назвала проверка: `/exit`, затем удалите его или оставьте и выполните `git worktree remove <path>` из основного checkout."
- bottom: "git worktree remove <path>"
- back: Y5 Внесите оба изменения, прежде чем что-либо удалять.

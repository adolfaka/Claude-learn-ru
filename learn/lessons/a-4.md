### W1 | Worked example step 1 of 4 | Запросите два факта в JSON
- tier: challenge
- skill: ask
- where: terminal
- beat: do
- skill: headless-run
- verify: json .practice/a-4-first.json subtype=success fresh
- goal: "Запросите два факта, которые может прочитать скрипт, и сохраните JSON:"
- code: point 1
```bash
claude -p "Одним предложением: что делает этот репозиторий и какая команда запускает его тесты?" --output-format json --permission-mode dontAsk --json-schema '{"type":"object","properties":{"summary":{"type":"string"},"test_command":{"type":"string"}},"required":["summary","test_command"]}' > .practice/a-4-first.json
echo "exit $?"
jq '{is_error, subtype, num_turns, session_id}' .practice/a-4-first.json
jq '.structured_output' .practice/a-4-first.json
```
- hint: "Проверяйте код завершения и `is_error`, прежде чем использовать `result`."
- beat: do
- skill: headless-run
- verify: json .practice/a-4-first.json structured_output.test_command
- note: "затем объект с `summary` и `test_command`, например `"npm test"` (значения у вас будут другими)"
- say: Готово, когда сохранённый JSON содержит команду тестов в структурированном выводе.
- hint: "Скрипт читает одно поле, как это делает `jq -r '.structured_output.test_command // empty'`, и останавливается, если оно пустое."

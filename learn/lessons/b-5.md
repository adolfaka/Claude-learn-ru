## ladder

### в закоммиченном CLAUDE.md есть правило, что каждый новый файл JavaScript в `src/` начинается с заданной строки
- narrow "Закоммиченного CLAUDE.md нет.": Закоммичен ли проверенный файл инструкций проекта?
- narrow "нет строки вроде": Называет ли закоммиченная инструкция нужную первую строку?
- narrow "не говорит, к каким файлам": Ограничено ли правило исходными файлами JavaScript?
- back: W2 Вернитесь к выбору и результатам этого шага, прежде чем снова пробовать то же действие.

### коммит, сделанный после этого правила, добавляет файлы JavaScript в `src/`, и каждый из них начинается со строки из правила
- narrow "Сначала закоммитьте CLAUDE.md": Закоммичено ли правило до того, как вы попросили новый исходный файл?
- narrow "В git нет коммита": Может ли git найти коммит, который ввёл это правило?
- narrow "эти новые файлы ещё не закоммичены": Закоммитила ли новая сессия созданный ею исходный файл?
- narrow "В новой сессии попросите изменение": Добавила ли более поздняя сессия новый исходный файл после правила?
- narrow "эти новые файлы не начинаются": Совпадает ли первая строка каждого добавленного исходного файла с правилом?
- back: W3 Вернитесь к выбору и результатам этого шага, прежде чем снова пробовать то же действие.

### закоммиченный CLAUDE.md содержит правило из заметок об ошибках CLI, а каждый скрипт `npm run`, который он называет, есть в `package.json`
- narrow "Закоммиченного CLAUDE.md нет.": Закоммичен ли проверенный файл инструкций проекта?
- narrow "нет правила из заметок": Есть ли проверенное соглашение об ошибках CLI в общих инструкциях?
- narrow "не разбирается как JSON": Разбирается ли конфигурация проекта, чтобы можно было проверить её скрипты?
- narrow "такого скрипта нет": Называет ли эта инструкция скрипт, который действительно существует?
- back: Y1 Вернитесь к выбору и результатам этого шага, прежде чем снова пробовать то же действие.

### закоммиченный `.gitignore` исключает `CLAUDE.local.md`, git не отслеживает `CLAUDE.local.md`, а в закоммиченном CLAUDE.md нет ни одной из личных заметок
- narrow "Закоммиченного CLAUDE.md нет.": Закоммичен ли проверенный файл инструкций проекта?
- narrow "git отслеживает": Отслеживает ли git всё ещё личный файл инструкций?
- narrow "всё ещё есть в вашем последнем коммите": Закоммичено ли удаление личного файла инструкций?
- narrow "Ни один закоммиченный `.gitignore`": Покрывает ли личный файл общее правило игнорирования?
- narrow "не даёт игнорировать": Не отменяет ли более позднее исключение правило игнорирования личного файла?
- narrow "игнорирует только `.git/info/exclude`": Закоммичено ли правило игнорирования и для коллег?
- narrow "но это правило не закоммичено": Закоммитили ли вы правило игнорирования личного файла?
- narrow "касается только вас": Не остался ли в файле команды личный путь или глобальная привычка?
- back: Y1 Вернитесь к выбору и результатам этого шага, прежде чем снова пробовать то же действие.

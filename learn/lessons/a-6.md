## intro
- minutes: "около 20 минут"
- why: "дать всей команде один набор Claude Code из git, а каждому — способ отказаться без коммита"
- can: "коммитить настройки, которые должны быть у всех, не пускать свои личные файлы в git и давать команде плагин, который загружается из marketplace (каталога плагинов) внутри репозитория"
- payoff: "коммитить настройки, которые должны быть у всех, не пускать свои личные файлы в git и давать команде плагин, который загружается из marketplace (каталога плагинов) внутри репозитория"
- read: "[A team's shared settings](https://code.claude.com/docs/ru/settings-example#a-teams-shared-settings): полный закоммиченный файл настроек, с которым можно сравнить свой."
- need: "bash, `curl` и git в macOS, Linux или WSL 2."
- need-repo: "Ваш репозиторий с настройкой среднего уровня"

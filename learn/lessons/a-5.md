## ladder

### закоммиченный рабочий процесс запускает `anthropics/claude-code-action`, закреплённый на релизе или SHA коммита, в автоматическом режиме, с учётными данными из секрета и без них в файле
- narrow "Нет закоммиченного рабочего процесса, который запускает": Есть ли уже файл рабочего процесса в коммите?
- narrow "не закоммичен. Выполните `git add": Добавили ли вы новый файл перед коммитом?
- narrow "но это изменение не закоммичено": Закоммичена ли ваша последняя правка рабочего процесса?
- narrow "Нужен второй рабочий процесс": Закоммиченный рабочий процесс — тот, что вы запускаете вручную, или тот, что ждёт упоминания?
- narrow "запускает Claude с `prompt`, но": Запускается ли рабочий процесс вручную и ни на чём другом?
- narrow "похоже на ключ API или токен Claude": Не попали ли учётные данные в сам файл?
- narrow "без версии": Указано ли в строке с действием, какой релиз запускать?
- narrow "короткий SHA коммита": Записан ли SHA закреплённого коммита полностью?
- narrow "может сдвинуться на новый релиз": Указывает ли закрепление на один релиз, а не на сдвигающийся тег?
- narrow "поэтому Claude ждёт": Даёт ли шаг Claude задачу, чтобы он работал сразу после старта рабочего процесса?
- narrow "пуст. Напишите там, что должен сделать Claude": Говорит ли задача для Claude, что делать?
- narrow "не передаёт учётных данных": Передаёт ли шаг действию учётные данные?
- narrow "берётся не из секрета": Берутся ли учётные данные из секрета репозитория?
- narrow "Уберите `pull_request_target`": Запускается ли рабочий процесс на чём-то, кроме вашего ручного запуска?

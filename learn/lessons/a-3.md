## intro
- minutes: "около 20 минут плюс время запуска"
- why: "сохраните аудит релиза командой, сообщающей только находки, подтверждённые вторым агентом"
- can: "держать одну сессию в работе, пока не пройдёт проверка, которую вы можете запустить"
- can: "сохранять аудит, который расходится по многим файлам и в котором каждую находку проверяет второй агент, как команду workflow, берущую папку из `args`"
- payoff: "сохранять аудит, который расходится по многим файлам и в котором каждую находку проверяет второй агент, как команду workflow, берущую папку из `args`"
- read: "[Compare ways to keep a session running](https://code.claude.com/docs/ru/goal#compare-ways-to-keep-a-session-running): `/goal`, `/loop` и Stop hook, и что запускает каждый следующий ход."
- need-repo: "Один из ваших репозиториев с проходящей командой тестов, например `npm test`, и миграцией, которая нужна одной небольшой папке"

## ladder

### закоммиченный скрипт в `.claude/workflows/` первой инструкцией содержит литеральный `export const meta` с `name` и `description`; скрипт читает входные данные из `args` и вызывает `agent()` как минимум дважды
- narrow "Нет ни одного скрипта workflow в": Вы сохранили запуск с экрана хода работы в папку workflows проекта?
- narrow "не закоммичен. Выполните": git status всё ещё показывает сохранённый скрипт как новый или изменённый?
- narrow "его игнорирует. Выполните `git add -f": Скрывает ли правило игнорирования сохранённый скрипт от git?
- narrow "но проверка читает только `.js`-файлы прямо в этой папке": Скрипт лежит во вложенной папке или сохранён с другим расширением?
- narrow "не начинается с `export const meta`": Стоит ли в закоммиченном скрипте код перед строкой meta?
- narrow "что-то кроме литеральных значений": Есть ли в объекте meta переменная, вызов или spread?
- narrow "непустая строка": Не хватает ли в объекте meta имени или описания?
- narrow "не компилируется": Есть ли в закоммиченном скрипте синтаксическая ошибка?
- narrow "нигде не читает `args`": Закоммиченный скрипт всё ещё сам называет свою папку?
- narrow "упоминает `args` только в комментарии": args встречается только в комментарии, строке или имени свойства?
- narrow "объявляет собственную переменную `args`": Объявляет ли скрипт переменную с именем args?
- narrow "нигде не вызывает `agent()`": Запускает ли скрипт хоть одного субагента?
- narrow "вызывает `agent()` только один раз": Проверяет ли второй агент каждую находку, прежде чем о ней сообщить?
- hint: "прочитайте его подсказку: она называет строку или часть скрипта, которую нужно изменить, а исправление вы закоммитите."

## ladder

### закоммиченный `.claude/settings.json` включает плагин из одного из marketplace Anthropic
- narrow "который читается как JSON": Закоммичен ли файл настроек и читается ли новый блок рядом с прежними ключами?
- narrow "не включает ни одного плагина из marketplace Anthropic": Стоит ли в записи после знака @ имя marketplace и включена ли она?
- hint: "Если не прошёл первый пункт, проверьте имя после `@`: это имя marketplace, `claude-plugins-official`, а не его репозитория."
- back: Y1 Вернитесь здесь к общей записи.

### `.practice/i-8-plugins.json`, сохранённый в этом репозитории, показывает, что этот плагин установлен на уровне проекта и включён
- narrow "В репозитории выполните": Сохранён ли список в репозитории, который читает проверка?
- narrow "— не JSON": Добавили ли вы флаг вывода в JSON, а не сохранили список для чтения человеком?
- narrow "не показывает": Установили ли вы плагин на уровне проекта в этом репозитории и сохранили ли свежий список?
- hint: "Флаг `--json` важен: список для чтения человеком — не JSON."
- bottom: "claude plugin list --json > .practice/i-8-plugins.json"
- back: Y3 Вернитесь здесь к установке на уровне проекта.

### плагин code intelligence, который вы пробовали, установлен здесь на локальном уровне, а закоммиченные настройки его не включают
- narrow "В репозитории выполните": Сохранён ли список в репозитории, который читает проверка?
- narrow "— не JSON": Добавили ли вы флаг вывода в JSON, а не сохранили список для чтения человеком?
- narrow "не показывает ни одного плагина code intelligence на локальном уровне": Установили ли вы языковой плагин только для этого репозитория и сохранили ли список после этого?
- narrow "поэтому вашу пробу получит каждый коллега": Не попал ли ваш языковой плагин в enabledPlugins общих настроек?
- hint: "Если не прошёл пункт про пробу, установите плагин своего языка на локальном уровне, не добавляйте его в `enabledPlugins` в `.claude/settings.json` и снова сохраните список."

- back: W2 Вернитесь здесь к локальной пробе.

## Уроки `learn/lessons/<id>.md`
Формат разбирает `learn/lib/content.mjs` (`parseLesson`). Правила:
- Заголовки шагов: `### W1 | Worked example step 1 of 6 | Run the installer` — переводится ТОЛЬКО часть после
  последнего ` | ` (здесь «Run the installer»). `Worked example`, `Your turn`, `The task`, `Tear down`,
  `Check`, `Warm-up`, `step|part N of M`, идентификаторы `W1/Y2/T1/D1/C/R1` — не трогать.
- Разделы `## intro`, `## steps`, `## ladder`, `## card` и т. п., ключи `- key:` (до двоеточия),
  служебные значения (`tier`, `skill`, `where`, `beat`, `verify`, `safety`, `watching` если это путь,
  `evidence`, идентификаторы шагов в `back: W1 …` — только первое слово) — не трогать.
- Фронтматтер: `title` — перевести; `stamp` — `"Проверено на Claude Code vX.Y.Z (stable) YYYY-MM-DD"`;
  `page`, `stuck` — заменить домен руководства (см. «Ссылки»); `badge` — НЕ трогать (это идентификатор,
  отображаемое имя переводит `copy.mjs`); `source`, `source-commit`, `next`, `lesson` — не трогать.
- Значение в двойных кавычках — дословная цитата со страницы руководства (`source:`). Перевод цитаты:
  1. найдите эту фразу в английском оригинале страницы: `git -C /Users/elliot/Downloads/claude-code-ru show 676831f:<source>`;
  2. найдите тот же абзац в русской странице `/Users/elliot/Downloads/claude-code-ru/<source>` (переведена по
     более старому коммиту b97a62b; якоря `<a id>` у заголовков совпадают с английскими — по ним удобно искать);
  3. если смысл абзаца тот же — возьмите русский текст ДОСЛОВНО (нужный кусок); если абзаца нет или он изменился —
     переведите сами по словарю, ближе к стилю русской страницы.
  Кавычки оставить кавычками, значение без кавычек — оставить без кавычек (это «свои слова» приложения).
- Если в «своих словах» (без кавычек) есть `` `команда` `` или `/команда`, она должна дословно встречаться в цитатах
  того же шага (тест `learn-content.test.mjs:218`). Не добавляйте новых команд в свои слова.
- Промпты, которые ученик вводит в Claude Code (`- prompt:`/`- run:` с текстом для Claude, блоки text) — переводить
  на русский; shell-команды — нет. Если проверка урока ищет в файле ученика английскую фразу из промпта — синхронно
  поправьте проверку.
- Строка `- say: Done when …` (без кавычек) по-русски начинается ровно с «Готово, когда » — её узнаёт
  регулярка в `content.mjs`.
- Плейсхолдеры в командах `<your practice copy>`, `<your repo>` и подобные `<…>` — НЕ переводить: код
  приложения ищет их в тексте и подставляет путь.
- `## ladder`: заголовок `### <текст пункта проверки>` должен ДОСЛОВНО совпадать с `text` пункта в
  `checks/lessons/<id>.mjs`. `- narrow "<фрагмент>": <вопрос>?` — фрагмент должен дословно входить ровно в одну
  подсказку FAIL этой проверки (после перевода подсказки), вопрос — по-русски и заканчивается на `?`.
  `back: W1 <текст>` — перевести текст после идентификатора.
- `- minutes:` — по шаблону словаря: «около 20 минут», «около 20 минут плюс время запуска», «от 30 до 60 минут».

## Проверки `checks/lessons/<id>.mjs`
`title`, `text` пунктов, строки подсказок, которые возвращает `check` (всё, что не `true`). Подстроки, по которым
сравнивается вывод программ или содержимое файлов, — не трогать, если файл ученика/шаблона остаётся английским.
Количество `return` в `check` не менять (тест считает их). Сценарии `checks/test/ladders/<id>.mjs`: если сценарий
кладёт в файл текст, который проверка ищет, и вы перевели этот искомый текст — поправьте сценарий.

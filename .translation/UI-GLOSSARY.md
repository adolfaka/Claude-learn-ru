# Единые формулировки интерфейса и уроков

Дополняет `claude-code-ru/.translation/GLOSSARY.md`. Если термина тут нет — смотрите тот словарь и
`Claude-learn-ru/learn/lib/copy.mjs`.

## Уровни и разделы
| Оригинал | Перевод |
|---|---|
| Beginner / Intermediate / Advanced (название уровня) | Начальный / Средний / Продвинутый (уровень) |
| Beginner path | Путь начального уровня |
| level index | оглавление уровня |
| lesson N | урок N |
| capstone | итоговый проект |
| Beginner capstone | итоговый проект начального уровня |
| elective | дополнительный урок |
| warm-up | разминка |
| worked example | разбор на примере |
| your turn | ваша очередь |
| the task | задание |
| tear down | уборка |
| check (проверка урока) | проверка |
| hint | подсказка |
| step N of M | шаг N из M |
| map (of lessons) | карта уроков |

## Предметы
| Оригинал | Перевод |
|---|---|
| practice copy | учебная копия |
| new copy (a-5, итоговый проект продвинутого уровня) | новая копия |
| work folder | рабочая папка |
| your repository | ваш репозиторий |
| learning app | учебное приложение |
| terminal / other terminal / second terminal | терминал / другой терминал / второй терминал |
| self-check | самопроверка |
| badge | значок |
| every command shown / the goal, hints if you ask / just the goal | показана каждая команда / цель, подсказки по запросу / только цель |
| guided / hinted / challenge (уровни помощи, если показаны) | с подсказками всех команд / с подсказками по запросу / только цель |
| not yet | пока нет |
| done | готово |

## Сомнительные места

1. **`CLAUDE.md` в корне шаблона конфликтует с курсом.** Ученик получает его в своей копии:
   - урок b-5 учит создавать `CLAUDE.md` через `/init`, а файл уже есть (с текстом для сопровождающих перевода);
   - b-4 говорит «в вашей копии ещё нет `CLAUDE.md`», и `/context` покажет его в memory files;
   - Claude Code грузит этот файл в каждую сессию ученика во всех уроках.
   Проверки на `main` пройти не должны (Assert checks требует, чтобы на `main` каждая проверка падала).
   Поэтому в тексте специально нет `npm test` (по нему проверяет b-capstone; написано `npm run test`),
   `linkcheck:` (b-5, пункт 3), «starts with the line `…`» (b-5, пункт 1) и импортов `@path` вне
   backticks (i-2). Импорты и `npm run`-скрипты я проверил функциями самих проверок: импортов нет,
   все скрипты есть в `package.json`. Но на уроки b-4 и b-5 файл всё равно влияет. Стоит решить:
   оставить его (как в старом `Claude-learn-ru`), убрать из `main` или держать вне шаблона.
2. README цитирует «пока нет» и «проверено локально» из сводки `checks/run.mjs --summary`, но сейчас
   `run.mjs` печатает `not yet` / `checked locally`. Если `run.mjs` не переведут, README нужно
   поправить на английские строки (или перевести `run.mjs` синхронно).
3. `.translation/README.md` перечисляет, что переведено (уроки, `copy.mjs`, проверки, `capstone/`). Это
   описание плана по брифу, не проверка факта: файлы других агентов я не смотрел.
4. В alt и в CLAUDE.md имя талисмана — `Pip` латиницей, как в старом `copy.mjs`.

## Что осталось английским и почему

- Название руководства «Claude Code: Everything You Need to Know» в тексте ссылки и «Claude Code practice» в H1 — имена продуктов/проектов (как в старом переводе).
- **Use this template**, **Create a new repository**, **Progress**, **Assert checks**, `PASS`/`FAIL`, `Paste code here if prompted`, текст ошибки `/proc` — надписи интерфейса и вывод.
- Названия страниц документации в ссылках (Dev containers, Sandboxing, Codespaces billing) — по правилу 4 словаря.
- `Dev Container Feature`, `stable`, `solutions`, `main`, команды, клавиши, переменные окружения.

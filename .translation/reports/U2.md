## Переведено в render.mjs
- `'Capstone'` / `` `Lesson ${n}` `` → `'Итоговый проект'` / `` `Урок ${n}` `` (подставляется в `C.lessonDone(label)`)
- `` `${total} of ${total}` `` → `` `${total} из ${total}` `` (2 места, шапка экрана «пройдено»)
- `✓ .practice/ exists` → `✓ .practice/ есть` (выбрано короткое слово, чтобы уложиться в запас `cw + 22`; константу не менял)
- `← not this one` → `← не этот`
- `<путь> holds <текст>` → `<путь> содержит <текст>`; во второй строке переноса `max - 6` → `max - 9` (длина «содержит »)
- `'your files'` → `'ваши файлы'` (запасной объект для `C.watching`)

## Оставлено английским
- `'LEARN'` (пилюля-логотип) — в старом переводе тоже оставлено.
- `'Warm-up'`, `'Check'`, `'new copy'`, `'git-clean'`, `'practice-dir'` и т. п. — сравнения со служебными значениями из уроков.
- `'<your repo>'`, `'<your practice copy>'` — плейсхолдеры, которые ищутся в тексте уроков (если переводчики уроков их переведут, надо синхронизировать здесь — лучше не переводить).
- `'git status'`, `cd …`, `npm run check -- …` — команды.

## Проверить в copy.mjs (другому агенту)
- `C.levelUp`, `C.complete` рисуются баннером из FONT: допустимы только буквы из FONT (латиница L E V U P C O M T и добавленные О Е Р Н В Ы Й У Л Ь П Д). Варианты «НОВЫЙ УРОВЕНЬ», «ПРОЙДЕНО» уже работают; другие буквы уронят рендер (`FONT[ch]` undefined).
- `C.lessonDone(label)` — label теперь «Урок N» / «Итоговый проект» (оба м. р.: «… пройден!»).
- `C.watching/staleWatch/stalePush(what)` — `what` может быть «ваши файлы» или `git status`.
- `C.itemOf`, `C.itemsShown`, `C.session(count)`, `C.stepDone(n)` — числительные, нужен `pl`.

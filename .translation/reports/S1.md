## Что осталось английским и почему
- `PASS` / `FAIL` в выводе `npm run check` — служебные метки; на них ссылаются уроки и тесты.
- `probeError` в probes.mjs (`unknown probe …`, `probe … takes …`) — ошибки разбора файлов уроков для автора (их ловит `learn/lib/content.mjs`), ученик их не видит.
- `watching:` в `PROBES` — это команды git (`git worktree list` и т. п.).
- Комментарии, регулярки, ключи — не трогал.

## Сомнительные места / заметки для агентов уроков
- **a-6.mjs:181** делает `commitHint(repo, missing).replace(/^`[^`]+` /, 'it ')`. Русский `commitHint` начинается с «`` `X` не закоммичен…``», так что регулярка по-прежнему срезает имя файла, но подставлять надо не `'it '`, а, например, `'он '` («…, но он не закоммичен…»).
- `commitHint` теперь: «`` `X` `` не закоммичен» (мужской род — «файл»/«каталог»). Для папки звучит приемлемо.
- `nameProblem` возвращает клаузу после `` `${path}` ``: «называет marketplace …», «не содержит `name`».
- `stub-claude` `run.refused` — клауза после `` `${script}` ``: «запускает Claude Code через `npx`», «меняет `PATH`» и т. д.
- `workflow-script` `what` — существительное в винительном падеже («функцию», «переменную, `x`», «пропуск вместо значения», «не литерал объекта»), чтобы читалось в «`meta` содержит ${what}».
- `parseJson` error (BOM) начинается со строчной: «он начинается с метки порядка байтов UTF-8…» — ставится после «…некорректный JSON: ». Если урок строит свою фразу с этим error, учтите.
- `marketplaceHint(repo, start)`: `start` вставляется как «${start}, и закоммитьте его.» — урок a-6 передаёт свой `page.marketplace`, его нужно перевести так, чтобы фраза сошлась.
- Ветки в probes: «Ветка X …», «У ветки X пока нет upstream…».

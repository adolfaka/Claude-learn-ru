## Ключи, которые добавлены в copy.mjs
- `TERMS.levelsGen` — родительный падеж перед «уровня» (`начального/среднего/продвинутого`).
- `BADGES` (export) и `badgeName(name)` (export): отображаемые имена значков; `C.badge(name)` выводит `badgeName(name)`.
- `C.plainDone`, `C.plainBroken(error)`, `C.plainItems(n, m)`, `C.plainSlow(id, n)` — для plain.mjs.
- `C.bytes(n)`, `C.kilobytes(n)` — для holds.mjs.
- Ничего не переименовано; сигнатуры прежние. `C.levels === TERMS.levels` сохранено.

## Шаблоны с уровнем
`levelPath` → «Путь среднего уровня»; `warmup(n, level)` → «Разминка из урока 3 среднего уровня»; `warmupIndex` → «Разминка из оглавления среднего уровня»; `folderPrompt` → «Рабочая папка для среднего уровня»; `folderAsk` → «Где вы хотите проходить средний уровень?».

## Сомнительные места / для других агентов
- **Плоский режим (LEARN_PLAIN/--plain): render.mjs (U2) заменяет каждый символ не из ASCII на `?`** (`ascii()` около строки 379), из-за этого весь русский текст выходит как `????`. Надо пропускать кириллицу (U+0400–U+04FF) и, наверное, «—», ««»», «…» тоже.
- Строки уроков `- say: Done when …`: переводчикам уроков начинать их с «Готово, когда » (так регулярка content.mjs по-прежнему ставит флаг `doneWhen`). `C.doneWhen` = «Готово, когда ».
- `C.levelUp` = «НОВЫЙ УРОВЕНЬ», `C.complete` = «ПРОЙДЕНО» — только буквы, которые U2 добавил в шрифт баннера.
- Названия уроков в списке (`check.title`) и `minutes` на экране вступления берутся из checks/lessons и learn/lessons — это другие агенты.
- Сообщения разбора урока в content.mjs (`fail(...)`, `throw new Error`) — для авторов уроков, ученик их не видит, и тесты их сверяют, так что они остались по-английски.
- `C.appName` = «Практика Claude Code»; пилюля `LEARN` в render.mjs осталась (это файл U2).
- Тесты learn-content.test.mjs проверяют английские TERMS/строки — они упадут, как и ожидалось; поправят отдельно.

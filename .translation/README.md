# Русский перевод учебного шаблона

Форк `wesammustafa/claude-code-practice`. Шаблон переведён по коммиту оригинала из `UPSTREAM_SHA`.

Уроки (`learn/lessons/*.md`) цитируют страницы руководства по коммиту `676831f` (поле `source-commit`).
Цитаты взяты дословно из русского руководства `runowata/claude-code-ru` там, где абзац русской страницы
совпадает по смыслу с английским по этому коммиту (русские страницы переведены по более старому коммиту
`b97a62b`); остальное переведено по словарю, ближе к стилю русской страницы.

## Словари и правила

- `.translation/BRIEF.md` — порядок перевода этого репозитория: что трогать, что нет, как сверять уроки.
- `.translation/UI-GLOSSARY.md` — единые формулировки интерфейса и уроков, отображаемые имена значков.
- `.translation/GLOSSARY.md` в `runowata/claude-code-ru` — общие правила и термины Claude Code.

## Что переведено

- `learn/lessons/*.md`: заголовки шагов (часть после последнего ` | `), цитаты, собственные слова
  приложения, промпты для Claude, пункты `## ladder`; в `title` и `stamp` фронтматтера.
- Видимые строки `learn/lib/*.mjs` (в первую очередь `copy.mjs`, в нём же функция `pl` для числительных).
- Названия и подсказки проверок `checks/lessons/*.mjs`; сценарии `checks/test/ladders/*.mjs` подогнаны.
- `README.md`, `capstone/*.md`, шаблон issue `.github/ISSUE_TEMPLATE/track-my-progress.md`.
- Ссылки: `code.claude.com/docs/en/` → `code.claude.com/docs/ru/`, руководство →
  `runowata/claude-code-ru`. Ссылка на шаблон `wesammustafa/claude-code-practice` не изменена.

## Что не переведено

- `src/`, `test/`, `samples/` — учебный проект linkcheck; его вывод и тесты остаются на английском.
- Подписи шагов в уроках (`Worked example step N of M`, `Your turn`, `Check`, `Warm-up` …) и
  идентификаторы шагов — их читает парсер, ученику они не показываются.
- Значения `badge` в уроках — идентификаторы; отображаемое имя значка переводит `copy.mjs`.
- Служебные ключи и значения уроков (`tier`, `skill`, `verify`, `source`, `source-commit` и т. п.),
  комментарии в коде, имена переменных, HTML-комментарии.
- Надписи интерфейса Claude Code, команды, пути, флаги, переменные окружения, вывод git/npm/claude.
- Тесты `checks/test/*.test.mjs` и `checks/test/learn-drive.mjs` — подгоняются отдельно.

`.translation/CLAUDE.md` — заметки о репозитории для сопровождающих перевода. Он лежит здесь, а не в корне:
в корне шаблона CLAUDE.md быть не должно — его создаёт сам ученик в уроке b-5 (`/init`), а Claude Code
подгружал бы его в каждую сессию ученика.
